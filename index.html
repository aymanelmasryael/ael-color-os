Color System Architecture

Primary & Secondary

Anchor colors derived from semantic vector analysis. The hue is computed from weighted industry and audience dimensions.

Semantic Status Colors

Success, Warning, and Danger are automatically generated from your anchor hue with optimized saturation and lightness.

Surface & Typography

Background, surface, and text colors are computed for optimal readability and WCAG AA/AAA compliance.

Smart Palette Strategy

Automatically selects Analogous, Complementary, Monochromatic, Split-Complementary, or Triadic based on your industry.

About AEL Color OS

AEL Color OS is a semantic color system generator that uses AI-driven vector analysis to transform project descriptions into complete, accessible color systems. Built for designers, developers, and brand strategists who need data-driven color decisions.

Tech Stack

  • Vanilla JavaScript (ES6+ Classes)
  • HSL/Hex/RGB Color Math
  • WCAG Contrast Ratio Engine
  • Semantic Vector Analysis
  • CSS3 Glassmorphism
  • HTML5 Semantic Markup
